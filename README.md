# Infografía «Cómo trabajo hoy» (kit)

Página que muestra con qué trabajas en Claude Code: herramientas, IAs, conectores, skills, scripts y proyectos. Diseño Aurora 2.

Uso rápido: edita `data.js` (autor, rol, base, home y tus ítems), luego:

```
python actualizar.py
python generador/build.py
```

y abre `index.html`. Detalle en `docs/COMO_FUNCIONA.md`.
